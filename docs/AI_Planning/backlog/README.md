# Home Inventory Backlog

Ideas for this application that are **not in any active plan**. Items land here when a planning review classifies them ⚠️ MAYBE, or when someone has an idea worth keeping that nothing currently needs.

Machine-wide or cross-project ideas go in `E:\MyProjects\MyBacklog\` instead.

## How to use

- **Add an item:** create `BL-###-short-name.md` (next free number) with the sections **Status**, **Origin**, **Idea**, **Why deferred**, **What it would take**, **Depends on**, **Revisit when**. Then add a row below.
- **Promote an item:** when a plan takes it on, set Status to `promoted`, name the plan and workstream (for example `summary_suggestions WS-4`), and record the scope change in that plan's DECISIONS.md.
- **Drop an item:** set Status to `dropped` and give the reason. Don't delete the file.

Status values: `parked` → `promoted` or `dropped`.
