# BL-006 — Report branding / white-labeling

- **Status:** parked
- **Origin:** [summary_suggestions GOALS.md](../support/summary_suggestions/GOALS.md) WS-3 (was ⚠️ MAYBE). Moved to the backlog by owner review on 2026-11-24.

## Idea
Let the report carry a logo, business name and colors: the owner's when offering a documentation service, or a reseller's if partners resell the licensed software.

## Why deferred
The first report version needs correct content, not branding. Licensing (WS-9) may change who needs branding, and how.

## What it would take
- A small branding settings block (logo file, name, accent color) stored in `app_settings`.
- Report templates that read it, with a plain default.

## Depends on
WS-3 report templates. WS-9 licensing decisions (whether there are resellers).

## Revisit when
WS-3 is done and WS-9 decides whether resellers or partners exist.
